🧠 agentic-rag
Agentic-RAG is an AI-powered Retrieval-Augmented Generation (RAG) system built for deploying custom knowledge-based agents. It integrates local document ingestion with dynamic query response generation, optimized for deployment on platforms like Vercel.

🚀 Features
Document ingestion (ingest_in_db.py)

Enhanced querying (agentic_rag.py)

Flask/FastAPI server (app.py, main.py)

Vercel-compatible deployment (vercel.json, Procfile)
